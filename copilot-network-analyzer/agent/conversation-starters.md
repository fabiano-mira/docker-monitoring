# Conversation starters

Copilot Studio → agent → **Overview → Conversation starters**. Four fit the UI.

| Title | Message |
| --- | --- |
| Network status | How is my network doing right now? |
| Top talkers | Which devices are using the most bandwidth? |
| Traffic mix | What kinds of traffic are on my network? |
| Recent alerts | Has anything unusual happened in the last 24 hours? |

Others worth keeping for testing:

- What is my Mac talking to right now?
- Show me every device sending traffic outside the country.
- Is the family fridge online?
- How much of my traffic is streaming video?
- Which host has the most open connections?
